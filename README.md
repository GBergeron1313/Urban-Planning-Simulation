
# Urban-Planning-Simulation
An advanced urban development simulator that lets urban planners and city
developers test infrastructure changes, population dynamics, and
environmental impacts in a real-time 3D environment.  

## What You Can Do
1. You’re able to place down buildings. Buildings can come in 3 types: Residential, Commercial, and Industrial. Zones of the city can be marked as “Restricted” to prevent building placement.
2. You’re able to place down roads. Just as with buildings, they can’t be in a “Restricted” area.
3. The people move through the city, from and to their place of work, home, and various stores.
4. The people are simulated, so metrics can be gathered, on a population scale, for percentage of time spent on the road, at work, etc.
5. Metrics for efficiency of travel between locations can be analyzed.
6. Population density has an effect on pollution, which can manifest as smog, should the city contain a high proportion of industrial buildings. 

## Getting Started
1. Clone the repository
2. Open in Unity 2022.3 LTS
3. Install required packages
4. Run the starter scene

## Tools Used

● Unity NavMesh

● C#
